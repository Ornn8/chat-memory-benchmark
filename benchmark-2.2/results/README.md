# 2.2 结果

> **读这一节再看数字。**
> 1. **榜单是完整的，但按抽样计分。** 短 / 长对话榜：每个榜按一个固定随机抽样打分（封存集每榜约 300 题，成对的题一起抽；所有系统用同一批题），开发集同理（每榜约 120 题）。原因是预算：百炼的向量 / 重排调用本身很慢，Qwen 基础方案要把整个历史一轮轮喂进去，每个榜的全部题要几个小时。正式比赛按全部封存题跑。
> 2. **全塞只算了一个小抽样**：短 / 长对话榜各 60 个单元（全部 60 题的成本按全部题折算）。**全塞怎么塞**：塞最近的、放得进 110k token 窗口的轮次——这个窗口在 M01 末尾只能放下最近约 2000 轮（共 7043 轮），在 M02 末尾只放得下最近约 400 轮（共 5413 轮，长信很长），更早的完全看不见。这和真实用 128k 窗口的模型一样。成本是这些窗口的输入价。
> 3. **自然用记忆榜**：我们的基线（BM25、无历史、从不提、见缝就提）跑了全部探针；Qwen 基础方案按类别比例抽样（封存 200 题、开发 50 题），成本按全部题折算；全塞抽样（封存 60 题、开发 30 题）。
> 4. **所有分数都带 95% 区间**，区间只反映抽到哪些题；两个分数的区间重叠，就不要说谁更好。**开发集分数不是榜单成绩**，见第 2 节的并排表。**2.1 和 2.2 的分数不能直接比较。** 结果只反映这两个合成人物。

## 6. 成本

C 是跑完这批题的人民币成本（系统自己的调用 + 记忆文本按 flash 输入价，价目表 prices-2.2.0；答题和判分不算）。本地基线没有模型调用，C 只有记忆文本的部分。

**一次封存跑要花你多少钱（Qwen 基础方案，实测后折算）**：Qwen 基础方案的每个调用都是百炼向量 / 重排（¥0.5 / 百万 token）。把整个历史喂进去的写入成本短对话榜 ¥0.23、长对话榜 ¥0.98，每道题检索约 ¥0.0016 / ¥0.0065。折算到一次完整封存跑（短对话榜 1107 题、长对话榜 1077 题）：**系统自己的用量约 ¥2.0（短）、¥8.0（长）**，远低于 ¥50 的上限。加上记忆文本进答题提示词的钱，C_ref 是 ¥1.12（短，284 题抽样）、¥4.76（长，285 题抽样）、¥11.48（自然，折算到全部题）。

## 7. 判分员校准（flash vs 独立阅读）

从基线回答里取 192 项（判分员判过 / 没过各约一半，来自 2.2 新题）；让 4 个独立的 Sonnet 读者在**不知道判分结果**的情况下，按同一份评分标准逐条判断是否通过。一致率 **92.7%**，Cohen's κ = **0.85**（判分员判过而读者判不过 8 项，反过来 6 项；判分员通过率 49.5%，读者 48.4%）。
说明：这一步是在历史矛盾审计之前做的，用的是当时的评分标准；读者是模型，不是人；样本按判分结果对半抽，所以通过率不代表真实分布；是在基线的回答上测的，高分系统的回答（更长、更细）上一致率可能更低。

## 9. 历史前后矛盾审计与隔离的题

生成的聊天历史里，同一件事的日期、星期、先后偶尔说得不一致。出题后，我们把每个事实组的台账设计、历史原文和该组全部考题交给独立读者（Sonnet）逐题核对（可以在全史里 grep 同一件事的其他提及），共核对 3081 道题（含当时的预留题）：**2629 道保留、375 道改了评分标准（依据记在题库里）、88 道隔离**（其中 12 道是孪生题的另一半，不计分、不删除）。读者共列出 879 条历史矛盾，大多数不影响任何考题。自然用记忆榜另外隔离了 17 道日期敏感的探针（所在事实组在主榜有题被隔离）。2.1 的旧轮次一字没改。
局限：审计是模型做的，我们核对了数量和配额，没有逐条复读原文；没有逐字通读整份历史。

## 10. 我们验证了什么、没验证什么

- 验证了：评测程序的计分单元、日常 / 长期分、聚类 bootstrap、成本上限（单元测试）；历史里原有每一轮一字不改（脚本逐轮核对）；每道新题的证据在截止轮之前；每道新题至少让另一家模型在「只给证据」或「把关键记忆放进提示」时通过（或由复核判为题没坏），不通过的已隔离；历史矛盾审计（上一节）；离线校验器 0 错误；泄漏哨兵。
- **没验证**：用更强判分员的复核；人类对题目的逐条审阅（复核是模型做的）；正式比赛才会用的全量封存跑（这里是抽样）；这些题对真实用户的代表性（只有两个合成人物）。
- 观察到的怪现象：（1）全塞在长对话榜上比 Qwen 基础方案低很多，因为长信让 110k 窗口只装得下最近约 400 轮；（2）开发集分数在短对话榜上比封存集高约 9 分（Qwen 基础方案 51.2 对 42.5），在自然用记忆榜上反而低（样本很小）；（3）到点主动提起所有检索类系统都接近 0。
