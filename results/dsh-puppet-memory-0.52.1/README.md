## 测试配置

- **记忆写入**：按 cutoff 递增，把每轮的「用户消息 + 助手回复」作为一条纯文本笔记写进被测插件的 `behavior/notes.jsonl`（`writeMemory({layer:"note"})`）。**写侧零模型调用**，不做摘要、不做向量化。
- **记忆隔离**：六个 persona 各自一个独立 `HOME`（插件按 `$HOME/.dsh/memory` 落盘），互不可见，也不与其它测试共享。
- **检索**：每题调插件自己的 `searchMemory(query, "all", 8)`，取前 8 条、截断 4000 字符；不外接向量/重排。
- **直接对话窗口**：固定给最近 **6 轮**转录（与评测方法一致），不使用更长的历史。
- **作答模型**：`deepseek-chat`（api.deepseek.com），system prompt 要求「只写记忆备忘录，没有证据写不知道」，每题一次，无重试。
- **逻辑时间**：按题目的 `now` 推进，历史只写到该题 cutoff 为止。
