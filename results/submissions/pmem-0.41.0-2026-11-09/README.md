## 测试配置

- **记忆写入**：按每题 `cutoff_turn` 增量回放六个合成人物的历史，每个考试节点使用该节点前的独立快照；
  考题与答案不写回历史。六个人物各自独立的记忆库。
- **注入给作答模型的材料**（四块）：
  1. 醒来卡 + 常驻三栏笔记（关于你 / 关于我 / 还没了的事）——由宿主在考试节点前按截止时间的状态离线整理；
  2. 检索结果：k=40、预算 2400 token；时间类问题走产品自带的收敛（k=8 / 600）；
  3. 原话通道：从 journal 原话按字面覆盖 + 时间衰减补最多 8 条；
  4. 最近六轮对话（带日期）。
- **默认参数改动**：三栏笔记与原话通道默认关闭，本轮通过配置打开：
  `{"notes":{"enabled":true},"retrieval":{"rawline":{"enabled":true}}}`。
  其余检索参数为产品默认值（未针对题库调整）。
- **作答模型**：`deepseek-v4.1-flash`，effort=low，temperature=0.2；随后同一模型对答案做一次自检改写
  （714 题中 266 题被改写，改写后的答案即本目录 `answers.jsonl`）。
- **判分**：本仓库 `grading/` 工具（`grade.py prepare/score`、`judge-prompt.md`），
  `deepseek-v4.1-flash`，effort=high，temperature=0.2，逐题按本题证据包判。
  两臂在同一判卷会话内完成，判分模型、提示词与并发一致。

## 局限

- **判分口径收紧**：判分只认本题证据包，真实但超出本题证据的补充会被扣分。作者对 96 道残留错题的精标显示，
  约 50 道属于「真话超范围」、16 道属于「要件答全但口径不对」——属于作答策略，不是检索能力。
- **三栏笔记依赖宿主生成**：产品默认关闭该模块；没有宿主的夜间整理就没有笔记内容。
- **保留期差异**：产品默认 journal 保留期是 30 天，回放使用 100000 天；原话通道在真实部署里只能吃到默认保留期内的原料。
- 作者侧自测，非维护者独立复现；判分者与配置见上，欢迎核对材料后要求补充说明。
