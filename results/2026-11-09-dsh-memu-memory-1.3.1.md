## 测试方式和边界

- 插件版本 `dsh-memu-memory` `1.3.1`，固定提交 [`2d65517`](https://github.com/Tkingxiao/dsh-memu-memory/tree/2d65517)。
- 记忆引擎 MemU `0.11.0b3`，`memoryBackend=api`、`vectorSource=local`；嵌入 `multilingual-e5-small`（int8 ONNX，384 维）；每个 Persona 使用独立 SQLite 向量库，代际 3；召回为 `managed-vector-rrf`（向量召回与词法 RRF 融合）。
- 每个人物使用一条种子会话，按考试截止点升序增量回放冻结历史；每个截止点先完成该段记忆整理，再重建记忆库后作答，避免考试回合的记录进入记忆。
- 直接对话提供最近六轮，更早内容由插件召回；作答模型不接收完整历史、标准答案或评分要点，题目和答案不写回后续记忆。
- 矛盾条目不替作答模型裁决：接受为 `active` 且 `coexist`，双方都保留，考试时由模型自行取舍。
- 整理使用 `dys-router` / `deepseek-v4.1-flash`（思考强度 **medium**）；作答使用同一模型（思考强度 **high**），按题目 rubric 信息点填空，明确不知道时写“不知道”；无关内容不补充。
- 判分主口径与本仓库一致：使用官方 `grading/judge-prompt.md` 判分，再用 `grading/grade.py prepare` 重建题包、`grade.py score` 汇总（677 / 714）。另附一份只评记忆复原的放宽口径（682 / 714）作参考，差异见“总成绩”。两份逐题判定均已提交，可复核。
- 461 个截止点全部完成，714 题全部作答；整理失败 7 次（均为重试路径），无宿主崩溃。
- 错题复跑参考：32 道错题用「整理 high / 作答 low」复跑，通过 17 题；该轮只整理了题目命中的 30 个截止点、未补齐中间 checkpoint，记忆覆盖不全，结果仅作参考。按比例推算，若 high 全程完整整理，全量约 699 / 714（97.9%）通过，属推算值。
- 本测试工具与聚合报告见 [Tkingxiao/memu-bench-714](https://github.com/Tkingxiao/memu-bench-714)，本版详细报告在 `docs/bench-1.3.1/`。

## 判分及逐题记录

判分模型为 `deepseek-v4.1-flash`，按官方题包（`question` / `now` / `rubric` / `facts` / `sources` / `answer`）逐题独立判定，单批最多 50 题，共 15 批；提示词使用本仓库 `grading/judge-prompt.md`。判分结果先以 `grade.py prepare` 生成官方同构 packets，再由 `grade.py score` 汇总为 `judgments.jsonl` 与 `summary.json`。

随本记录提交的逐题材料（714 行，题号与主数据集一致）：

- `2026-11-09-dsh-memu-memory-1.3.1-answers.jsonl`：`id` + `answer` 原始答卷。
- `2026-11-09-dsh-memu-memory-1.3.1-reviews.jsonl`：判分模型逐题原始输出（含 `required` 逐项布尔值、各类错误标记、`reason`）。
- `2026-11-09-dsh-memu-memory-1.3.1-judgments.jsonl`：归一化后的判定，含 `factual_pass` / `relevance_pass` / `pass` 与 persona、考点、间隔字段。
- `2026-11-09-dsh-memu-memory-1.3.1-summary.json`：`grade.py score` 输出的分组合计（persona / content_tags / interval_days）。

两项口径均由同一份 `reviews.jsonl` 按不同规则重算：主口径沿用官方 `grade.py` 规则，放宽口径仅把 `required` 中的建议 / 追问 / 表达方式类要点与 `无关旧事` 从失败条件中去掉。人物轨迹与完整流程见 [Tkingxiao/memu-bench-714](https://github.com/Tkingxiao/memu-bench-714)。
