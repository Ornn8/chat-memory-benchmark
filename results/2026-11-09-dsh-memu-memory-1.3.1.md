## 测试方式和边界

- 插件版本 `dsh-memu-memory` `1.3.1`，固定提交 [`2d65517`](https://github.com/Tkingxiao/dsh-memu-memory/tree/2d65517)。
- 记忆引擎 MemU `0.11.0b3`，`memoryBackend=api`、`vectorSource=local`；嵌入 `multilingual-e5-small`（int8 ONNX，384 维）；每个 Persona 使用独立 SQLite 向量库，代际 3；召回为 `managed-vector-rrf`（向量召回与词法 RRF 融合）。
- 每个人物使用一条种子会话，按考试截止点升序增量回放冻结历史；每个截止点先完成该段记忆整理，再重建记忆库后作答，避免考试回合的记录进入记忆。
- 直接对话提供最近六轮，更早内容由插件召回；作答模型不接收完整历史、标准答案或评分要点，题目和答案不写回后续记忆。
- 矛盾条目不替作答模型裁决：接受为 `active` 且 `coexist`，双方都保留，考试时由模型自行取舍。
- 整理使用 `dys-router` / `deepseek-v4.1-flash`（思考强度 **medium**）；作答使用同一模型（思考强度 **high**），按题目 rubric 信息点填空，明确不知道时写“不知道”；无关内容不补充。
- 本版判分口径是**只评记忆复原**：`required` 中属于“建议怎么做 / 应该追问 / 表达方式”的要点，只要记忆事实复原就算满足；`无关旧事` 不作为失败依据；失败只记记忆层面的硬错误（错认 / 错否 / 越界 / 编造日期 / 不当私事披露 / 违反禁止 / 未知当事实）。因此本记录与使用严格 `required` 判分的旧记录不宜直接横比。
- 461 个截止点全部完成，714 题全部作答；整理失败 7 次（均为重试路径），无宿主崩溃。
- 错题复跑参考：32 道错题用「整理 high / 作答 low」复跑，通过 17 题；该轮只整理了题目命中的 30 个截止点、未补齐中间 checkpoint，记忆覆盖不全，结果仅作参考。按比例推算，若 high 全程完整整理，全量约 699 / 714（97.9%）通过，属推算值。
- 本测试工具与聚合报告见 [Tkingxiao/memu-bench-714](https://github.com/Tkingxiao/memu-bench-714)，本版详细报告在 `docs/bench-1.3.1/`。

## 判分及逐题记录

DeepSeek V4.1 Flash 按题目标准和截止前历史独立判分，使用填空信息点核对，单批最多 50 题；判分结果按 `pass` / `error` 汇总，只有 `pass` 计入本表。

逐题答卷、判分记录和人物细节不在本 PR 中公开，本提交只包含聚合成绩与测试配置；完整评测流程与逐题结果见测试工具仓库。
