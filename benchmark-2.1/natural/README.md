# 自然用记忆榜（Bench 2.1 的第三个榜）

测的是：陪伴者**有没有自然地使用记忆**。

1. 该提的时候主动提（他说明天回家，她记得他妈妈生日；他说戒了奶茶，后来又点了一杯，她记得）；
2. 不该提的时候不翻旧账（他难过时、同一件小事隔几天说一遍、他叫她别提的事、已经做完或被更正的事、别人的隐私）；
3. 提的方式像人（「你上次说…」，不是数据库口气），拿不准就说拿不准，不编细节。

## 数据说明（请原样引用）

**题目设计基于已同意「帮助改进」的用户的聚合统计（比例、时间间隔、话题分布、情绪分布）。没有使用任何用户的原文；所有对话和题目都是合成的**：历史是 2.1 的两个合成人物（M01 宋雨橙、M02 孟远舟），题目的用户话和陪伴者的固定回复由模型按人物卡和合成历史生成，生成时的输入里没有任何真实用户的文字。

## 题的样子

一道题 = 人物历史（到截止轮为止）+ 一小段合成的「尾巴」+ 一个探针。

- **A 档（152 题）**：尾巴里陪伴者的回复也是固定的，所有系统看到相同的上文，只评探针那一句的回复。
- **B 档（16 题）**：4 句固定的用户话，陪伴者的回复由被测系统（经统一的答题模型）现场生成，逐句判分。用来测「同一件小事是不是反复提」「被叫停后会不会又提」。

| 类 | 含义 | 题数/人物 |
|---|---|---|
| X | 该提的时候要提：X1 说到未来的事、X2 习惯或约定变过、X3 长期状况、X4 今天到期、X5 没说完的事、X6 偏好 | 34 |
| H | 只记得一部分 / 根本没说过 / 两种说法矛盾：要说拿不准，不编 | 8 |
| Y | 不该提：Y1 他低落时、Y2 陈年小事反复、Y3 被叫停的事、Y4 已完成/已更正/还没到期、Y5 敏感或第三方隐私 | 26 |
| Z | 提不提都行 | 8 |
| N0 | 无关闲聊，不该硬塞旧事 | 8 |

两个人物各 84 题，共 168 题；开发集 34 题（本目录 `dataset/natural-probes-dev.jsonl` + `natural-key-dev.jsonl`，卡片全部公开），封存集 134 题只公布 SHA256（`dataset/natural-sealed-commitment.json`）。配比依据：她提旧事的轮次约占 9%（所以不该提的题和无关对照占一半以上，防止奖励「到处提」）；被翻的旧话 59% 在 4–30 天前（所以间隔以此为主，另加 31–180 天的合成长线）；用户低落占 4%（Y1 全部过采样为低落，另按真实占比还原一份分数供参考）。

## 记忆隔离与泄漏检查

- 评测程序只把截止轮之前的历史一轮一轮喂给系统，再喂尾巴，答完让系统 `rewind` 回到喂尾巴之前；系统的状态不会带到下一题。
- 记忆文本里出现截止轮+尾巴之外的轮次 → 泄漏；出现**别的题的尾巴** → 污染。两项都要求为 0。
- 泄漏哨兵（`natural_sentinel.py`，同 2.1 的金丝雀，qwen-base 与 bm25 各跑一遍）：强制隔离 0/24，故意泄漏的正对照 24/24（见 results/sentinel-*.json）。
- 卡片（应该提什么、不该提什么、诱饵、依据）只在判分时给判分员，不给被测系统。出题时检查：X 类题的尾巴和探针里不含旧事实的关键词；尾巴和探针不抄真实历史里的整行。

## 判分

见 [../SCORING.md](../SCORING.md) 最后一节：A 是想起侧 R（X、H）与克制侧 P（Y、N0、Z）的调和平均，所以「从不提」和「见缝就提」都拿不到高分；编造按「标出可疑处 + 复核」两步认定，对所有系统一视同仁。判分员是 DeepSeek flash（与另两个榜相同），对比式标准 `{what, not_for, examples}`；回忆检测、口吻（0/1/2）和对「其他回忆」的历史核查是三次独立调用，提示词在 `../harness/bench21/prompts/natural_*.md`。出题人写的参考回复用同一判分员打分作为天花板检查（见 `results/`）。

## 怎么跑

```bash
python -m bench21.natural run       --release ../dataset --natural dataset --system qwen-base --split dev --run mine
python -m bench21.natural judge     --release ../dataset --natural dataset --system qwen-base --split dev --run mine
python -m bench21.natural summarize --release ../dataset --natural dataset --system qwen-base --split dev --run mine
python -m bench21.natural_report --lb21 ../results/leaderboard-sealed.json --run mine --out out/
```

## 已知局限

- 判分员仍是 flash，和另两个榜一样没有人工金标；「口吻」一项判分员间一致性未单独校准，只展示、权重已含在 X 类里的 20%。
- 168 题的 A 标准误约 3.5 分，两个系统差 <7 分不要当作显著差别。
- 题目里「不该提」的比例是主人对产品的判断（用户很少明说嫌她提旧事，聚合数据里显式抱怨只有个位数），不是从投诉数据直接得到的。
- >30 天的间隔（占 20%）没有真实数据支撑，全部合成。
- 出题检查发现 2 道题（M02，一道开发集、一道封存集）的尾巴抄了合成历史里的整行，已重出；现在出题流程里有「整行抄历史」检查。
