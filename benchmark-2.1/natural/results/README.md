## 极端基线检验

自然榜 A 是想起侧 R 与克制侧 P 的调和平均（公式见 [../../SCORING.md](../../SCORING.md)）。

| 系统 | A | 与 r3 的差 | S | 与 r3 的 S 差 | 资格底线 |

| r3 | 47.7 | +0.0 | 47.7 | +0.0 | 是 |
| never-recall | 26.4 | -21.3 | 32.4 | -15.3 | 是 |
| always-recall | 40.0 | -7.7 | 44.9 | -2.8 | 否 |
| none | 22.0 | -25.7 | 28.0 | -19.7 | 是 |
| recent6 | 27.9 | -19.8 | 33.9 | -13.8 | 是 |

读法与已知问题：

1. 「从不提旧事」（never-recall）和 none 的 A 比 r3 低约 21–26 分，「见缝就提」（always-recall）低约 8 分，并且克制率只有 60%、编造率 13%，过不了资格底线。always-recall 的 S 只比 r3 低约 3 分，是因为它的成本只有 r3 的三分之一（成本项给它加了约 5 分）；它的 A 与 qwen-base、bm25-recent6 在同一水平，这三者差别在噪声内。
2. 出题人的参考回复在 A 档 152 题上 A=98.3（天花板检查，想起率 100%，编造 0%）。
3. 168 题的 A 标准误约 3–4 分，X 类只有 56 个判分轮次、H 类 16 个，不要读到小数点后。
4. **编造率**用「标出可疑处 + 复核」两步认定（SCORING.md 有写），对所有系统一视同仁，原始标记保存在 `fabrication_raw`。出厂前自己当第二判分员抽查：复核前被标的 12 个轮次里约 5–6 个是误报，复核后确认的 15 个里约 12 个是真的。
5. 想起检测的抽查：对 r3 的 56 个 X 轮次，抽 6 个判「想起」和 8 个判「没想起」，8 个「没想起」全对，6 个「想起」里 1 个存疑。
6. 三榜总排名只含三个榜都有成绩的系统；never-recall 与 always-recall 只在自然榜上。
