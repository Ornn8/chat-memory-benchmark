## 题目构成

- **旧题 574 道**（2.0 发布版，题面按“只改问法”改写 124 道，改动对照表见 `dataset/review-only/`）：27 个考点 × 5 个等待档（0 / 3 / 15 / 45 / 90 天）。
- **新题 91 道**（封存 76、开发 15）：
  - 暗考 + 「触发 / 不触发」对照：同一句话、条件成立与不成立各问一次，只会“一律提醒”或“一律不提”的系统最多拿一半。
  - 时间孪生：同一句话问两次，`now` 不同、答案不同；早期那一题同时是**泄漏哨兵**。
  - 真假前提孪生：同一件事，一题顺着说对的前提、一题顺着说错的前提，既查“乱认”也查“乱否认”。
  - 到期主动提起：用户只说一句无关的话，好的回复要主动带出今天到期的约定；配“没有东西到期”的对照。
  - 按日期找、聚合计数（小规模试点，见勘误里关于“闭包”风险的说明）。
- 两个榜都不单设“进阶榜”：新题直接并入各榜的封存集。
