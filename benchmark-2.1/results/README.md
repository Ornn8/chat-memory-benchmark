## 5. 必须说明的局限

1. 【已解决】此前百炼账号欠费、Qwen 检索只能回放旧记录；现已用生产密钥实时重跑（run R21），Qwen 的 A、C、S 和哨兵都是实时计量的结果。
2. 【已解决】新题 76 道上 Qwen 已有成绩，新题块有 C_ref 与 S。（四舍五入后的 A 可能与逐题明细差 0.01。）
3. **全塞基线是抽样作答**：短对话榜旧题 100 题 + 全部 48 道新题，长对话榜旧题 50 题 + 全部 28 道新题（按等待档分层、固定种子）；C 按全部共同题的提示词长度计，因为全塞一次作答约 8 万 token，全跑超出预算。抽样成绩误差较大，加权与不加权 A 的差距就是小样本所致。
4. **判分员与 Sonnet 的一致性 κ=0.66，低于规格目标 0.80。主人已接受**：所有系统都由同一个 DeepSeek flash 判分，排名对各系统是公平的；绝对分数带有判分员偏差（详见 `judge-checks.md`）。这是已记录的局限，不是阻塞项。
5. **价目表 prices-2.1.1**：百炼 Qwen 嵌入与重排均为 ¥0.5/百万 token（主人确认）；DeepSeek flash 的 $0.18/$0.72 是**由我们自己的账单拟合出来的，不是官方标价**（主人不知道官方价），知道后替换。C 的绝对数随价目表变，S 的形状（每翻一倍扣 3 分）不变。
6. 对照题（旧版“不该引用个人内容”）单列，不进 A；新题里的对照题进 A。
