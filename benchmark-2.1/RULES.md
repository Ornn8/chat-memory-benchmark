## 比什么

- 三个榜。前两个各用一个合成人物的完整聊天历史：
  - **短对话榜**：M01 宋雨橙（话痨型，短句，3000 轮、约 180 天）。
  - **长对话榜**：M02 孟远舟（长信型，2500 轮、约 180 天）。
  - **自然用记忆榜**（新增）：在同样两个合成人物的历史上，测系统有没有**自然地**使用记忆——该提的时候主动提、不该提的时候不翻旧账、提的方式像人、拿不准就说拿不准而不编。共 168 道题（开发集 34 道公开，封存集 134 道只公布 SHA）。**题目设计参考了已同意「帮助改进」的用户数据的聚合统计（比例、间隔、话题分布）；没有使用任何用户的原文，所有对话和题目都是合成的。** 详见 [natural/README.md](natural/README.md)。
- 每个榜有公开的**开发集**（题面、评分标准、参考答案都公开，可以随便调系统）和不公开题面的**封存集**（正式成绩只看封存集）。封存集题面的 SHA256 已写进 `dataset/sealed-commitment.json`，揭榜时可核对没有换题。
- 成绩与成本一起算，计分方法见 [SCORING.md](SCORING.md)（每个榜的综合分 S = A − 3 × log2(C / C_ref)，C 下限为 C_ref / 4；总排名是三个榜 S 的加权平均：短对话 37.5%、长对话 37.5%、自然用记忆 25%）。

## 奖品

一个 200 美元的 ChatGPT 订阅。同时满足三条才有资格：

1. 三个榜的加权平均综合分 S（37.5% / 37.5% / 25%）第一；
2. 三个榜的加权平均成绩 A 也高于 Qwen base（不能只靠省钱赢）；
3. 用宽松许可证开源（MIT / Apache-2.0 / BSD 等），并且所有模型调用都走评测网关（开源后任何人可以复查）；
4. **自然用记忆榜的资格底线**（不进 S，只是奖品条件）：克制率 ≥ 70%（不该提旧事的题里，没有乱提的比例），编造率 ≤ 5%（回复里把历史里没有的东西说成说过的比例）。一个靠「见缝就提」或编造拿高分的系统，没有资格。

## 参赛系统必须遵守

1. **只通过网关调用模型。** 对话模型、向量模型、重排模型的每一次调用都必须发往评测程序给出的网关地址（环境变量 `OPENAI_BASE_URL`，路径 `/chat/completions`、`/embeddings`、`/rerank`）。网关持有供应商密钥并按 `harness/bench21/prices.json` 计价；系统自己带密钥直连供应商的调用不被承认，查出来取消资格。本地模型也要放在网关后面：用 OpenAI 兼容服务起本地模型，在网关上设置 `BENCH21_LOCAL_URL`，系统里以 `local:模型名` 调用；网关转发并按服务返回的 token 数记账，按 DeepSeek flash 的价格计价。
2. **记忆隔离。** 评测程序按截止轮从小到大访问考点，只把截止轮之前的历史一轮一轮喂给系统（`ingest(turn)`），系统从来拿不到历史文件。检索 / 回忆接口（`retrieve(question, now, cutoff_turn)`）必须只读：不许把考题或答案写进记忆。
3. **不许读考题以外的东西。** 系统运行时只能拿到当前这一道题的 `question`、`now`、`cutoff_turn`。不得读取封存集题库、评分标准、其他考点的内容。
4. **泄漏哨兵。** 评测程序会在若干考点的「截止轮之后一轮」埋金丝雀，并检查时间孪生早期题是否出现只在截止轮之后才说过的内容。看到未来内容的系统，成绩作废并公开标注。
5. **自然用记忆榜的接口**：除 `ingest` / `retrieve` 外，系统要支持 `mark()` / `rewind(token)`：评测程序在截止轮之后喂给系统一小段合成的「尾巴」（1–5 轮对话，有的由系统自己的回复现场接上），答完再要求系统退回到 `mark()` 时的状态，避免上一题的尾巴污染下一题。不能回退的系统，评测程序会从头重放历史（相同输入只计一次费）。评测程序会检查：另一题的尾巴出现在本题的记忆文本里即判污染，成绩作废并公开标注。
6. **到期主动提起题**（用户只说一句无关的话，好的回答要主动带出今天到期的事）属于「主动使用记忆」：参赛系统可以在每次回复前做任何基于时间的检索或扫描（比如先查今天到期的约定），这是允许的，也是这类题要考的。
7. 答题模型和判分模型由评测程序统一提供（DeepSeek V4.1 flash，温度 0，关闭思考），参赛系统只提供「记忆文本」（`Retrieval.prompt`）。记忆文本的 token 按 flash 输入价计入 C。

## 榜单怎么写

- 每一行写清楚：系统名与版本、是谁跑的（我们或作者）、测试时间、环境（题库版本、答题 / 判分模型、检索组件）。
- 我们自己跑的系统用统一环境重跑；其他系统保留原来的成绩，并标注当时的环境，**不与 2.1 成绩直接排名**，除非按本规则重跑。
- 我们的 Qwen 基线（qwen-base）和几条参考基线（无历史、只看最近 6 轮、BM25 + 最近 6 轮、全塞）永远在榜上；自然用记忆榜另有两条极端基线：「从不提旧事」和「见缝就提」，用来检验题目不会奖励任何一种极端做法。

## 怎么参赛

1. 读 [harness/README.md](harness/README.md)，实现 `System` 适配器（`ingest` / `retrieve`）。
2. 在开发集上自测：`python -m bench21.runner --release dataset --system your-system --split dev --run mine`；自然用记忆榜：`python -m bench21.natural run --release dataset --natural natural/dataset --system your-system --split dev --run mine`（再 `judge`、`summarize`）。
3. 提交适配器代码和依赖、使用的模型清单。评测方在统一环境里跑封存集，公布 A、C、S 三列和泄漏哨兵结果。
